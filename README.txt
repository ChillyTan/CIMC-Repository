CIMC 文件结构

00_竞赛资料
存放 2025、2026 年赛题、细则、初赛说明等 PDF。

01_官方资料与例程
官方发布的例程、资料包。

02_工程代码
实际开发用的工程代码，包括 CIMC、GD32F4、网友参考代码等。

03_Bootloader
Bootloader、上位机烧录工具、Bootloader Demo。

04_硬件资料
开发板资料、原理图、PCB、芯片资料等。

05_算法与标定
MATLAB 脚本、PT100 温度标定表、拟合程序。

06_上位机与安装包
上位机软件、安装包、文件上传工具。

07_报名与提交材料
报名表、AI 使用声明、最终提交文档等。

99_其他归档
暂时不好分类或待整理的文件。
